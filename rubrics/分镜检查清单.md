# 分镜检查清单（输出前逐条过一遍）

## A. 能不能生成（AI 可行性）
- [ ] 每条生成单元都满足"四个一"：一个机位起止、一个主运镜、一条连贯动作链（≤2~3 个连着的小动作）、一套光
- [ ] 每条生成单元都写了运镜的**起点 → 方向 → 终点 + 速度**
- [ ] ❌ 级难镜头（4 人以上同框跳舞、唱段对口型、手部复杂手势、画面写字、精确频闪）都已降级或给了备选
- [ ] 每一刀都标了制作级别 L1~L4（只表示画面从哪来）；能用 L1 / L2 或复用已有 U 的没有新增 L3；L1 刀背后要生成的素材也算进了 U 的总数
- [ ] 文字、LOGO、UI、频闪、色彩跳变、变速、有人物的大角度旋转都放在 L1，没写进生成提示词
- [ ] 每条提示词都带了**质感层短句**；有人物的生成单元还带了**人物锚点短句**，且与全片锚点一字不差
- [ ] 该用首尾帧的地方（后拉揭示、推穿、穿洞、动作有明确起止）用了首尾帧
- [ ] 唱段近景都标了"对口型"或"不露嘴"
- [ ] 生成单元时长 = 供给镜头总长 + 头尾余量，且不超过模型上限；一条只拍一刀
- [ ] 每条生成单元写了跑法和挂哪些参考（`AI生成逻辑.md` G16）；要出首帧图的，首帧图是目标景别、动作开始前的姿势、位置写死、图里没有字（G14）
- [ ] 提示词对过一遍避坑清单（G15）：近景里没写地面、没写"全身"、没写"看不清面部"，群众写了在干什么看哪里，走路写了朝向和方向，速度写了"正常速度"

## B. 剪辑是否成立
- [ ] 每个 S 镜头都标明来源（L3 / L4：U 几第几秒；L2：P 几 + 动法；L1：素材 + 命令）
- [ ] 相邻两刀景别至少差一级、或机位角度明显变化、或明暗 / 颜色反差明显（不会像跳切）；定机位换景、换背景、AB 交替、点名闪切除外
- [ ] 镜头时长用"拍"写，并换算成秒
- [ ] 一般段落连续快切不超过 4 小节，中间有 ≥1.5 秒的稳定镜头（最后副歌 / 高潮冲刺可以例外，但要主题统一）
- [ ] 快切蒙太奇主题统一、内容变化，结尾撞在重拍上
- [ ] 每个转场都写了入点画面和出点画面
- [ ] 两条 AI 舞蹈素材的接缝处用了遮挡类转场（甩发 / 身体扫过 / 甩镜 / 黑断点）

## C. MV 感（女团 MV 的味道）
- [ ] 副歌有一个"看清动作"的锚点镜头（正面对称 / V 字阵），不是从头碎到尾
- [ ] 每个成员在本段至少有 1 个单人镜头（点名公平）
- [ ] 有至少 1 个"记忆点画面"（一个能截图当封面的镜头）
- [ ] 换世界时第一镜交代了空间（大远景 / 行进群像 / 尺度反差）
- [ ] 一段里构图种类控制在 3~4 种反复用，没有每刀都换花样
- [ ] 高潮爆点（白闪 / 碎镜 / 冲进光）全片不超过 3 次

## D. 交付完整
- [ ] 四块都齐：剪辑镜头表、静图清单、生成单元清单、代码与剪辑清单，并附分级统计
- [ ] 有唱跳时，说唱刀、舞蹈刀按人单列了一张表；首帧图清单按人分组
- [ ] 不确定的地方写进了"导演判断"
- [ ] 没有改动用户给的歌词、歌曲结构和人设

## E. 用户看片时最常挑的毛病（分镜时和每轮返修后都过一遍）
- [ ] **穿帮**：动作和人设冲突（人设里本来就有的东西又"画上去"）、人凭空出现、东西自己动、走反方向、群众死盯镜头
- [ ] **意义不明**：每刀都说得出"观众看到这刀明白什么"；抽象象征镜头（比如一滴水的升格特写）有前后交代，不然换掉
- [ ] **升格 / 黑屏**：有人物的慢动作、段落中间的黑一拍，都有理由且用户认可
- [ ] **重复**：相邻几刀不是同一个人、同一种拍法、同一个场景（除非是同一镜头的延续）；没有两刀内容差不多
- [ ] **太平**：音乐动感的段落每一拍都有东西（切、冲推、闪、甩发、群舞快切）
- [ ] **短刀多人**：单独一刀不到 1 拍时没放 4 人同框跳舞或四宫格（连着几刀的半拍群舞快切可以）
- [ ] **接得不顺**：两刀之间动作、方向、光衔接得上；入点没从素材第 0 帧开始、没定格第 0 帧
- [ ] **静图太死**：人像静图在半拍以内，并且带推镜 / 重影 / 错位这类代码运动

> 有任何一条 A 类不通过，必须改完再交。B、C、E 类不通过超过 3 条，建议重做节奏或重新设计这几刀。
