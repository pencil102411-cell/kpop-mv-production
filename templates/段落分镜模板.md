# 段落分镜模板（一个段落 / 30 秒以内 / 一段歌词）

> 用于：用户给一段歌词或一个段落（前奏、主歌、副歌……），要"这段怎么分镜"。
> 输出四块：**① 剪辑镜头表（S，每刀标制作级别 L1~L4）② 静图清单（P，给 L2 用）③ 生成单元清单（U，给 L3 / L4 用）④ 代码与剪辑清单（L1）**，最后附分级统计。

---

## 段落信息
- **段落**：（例：副歌 1，0:45~1:00，8 小节）
- **BPM / 一拍秒数**：（例：128 / 0.469 秒；未知则写"按 120 估，待校准"）
- **总拍数 / 总秒数**：（例：8 小节 = 32 拍 = 15 秒）
- **预计刀数**：（参考：副歌 8 小节一般 10~18 刀）
- **所在世界**：（例：世界 B·柠檬黄太空舱，黑色制服）
- **这段的任务**：（一句话：例"让观众记住副歌手势，并完成全员集结"）
- **节奏曲线**：（例：前 4 小节 2 拍一刀看编舞 → 第 5~6 小节半拍快切 → 第 7 小节白闪 → 第 8 小节剪影定格）

填写规则：
- **拍位**写"小节.拍"（第 2 小节第 1 拍 = 2.1）；后半拍加"+"（2.3+ = 第 2 小节第 3 拍的后半拍）。
- **时长**同时写拍数和秒数。
- **谁**：哪个成员（全员 / A / A+B），用来检查点名公平。
- **唱段/嘴**：这一刀是不是唱段近景——"对口型"（要用音频驱动工具）或"不露嘴"（闭嘴、侧脸、背影、剪影、遮挡）。
- **景别**：大远景 / 全景 / 中景 / 近景 / 特写 / 极近。相邻两刀景别至少差一级，或机位角度明显变化，或明暗颜色反差大（否则像跳切：画面好像抖了一下）。例外：定机位换景、同人同姿换背景、AB 交替、点名闪切是故意同构图。
- **构图、运镜、转场**尽量用库里的编号（构图库 A1~F2、运镜库 Y-M1~Y-T2、转场库 T1~T22），方便对照。
- **动效**写效果名和做法（例："白闪 2 帧，mvfx flash"）。
- **制作**填 L1~L4，只填这一刀的**画面从哪来**（判断方法见 `references/制作方式分级.md`）：能从已有 U 截出来的标 L3（复用，不加生成量）；单独一张脸 / 物件 / 地标、且画面里没有真实运动的用 L2；只对别的画面做剪接效果的用 L1。叠加效果写在"动效"列。L1 刀用到的素材要专门生成时，那条 U 也要列进 ③。
- **来自**：L3 / L4 写"U 几 第几秒"；L2 写"P 几 + 动法"；L1 写"用哪段素材 + 哪个命令 + 做出的文件名（`L1_S几_说明.mp4`）"。
