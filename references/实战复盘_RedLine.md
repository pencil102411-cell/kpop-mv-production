# 实战复盘：《Red Line》AI MV（2026-10-26 ~ 10-30）

> 一支四人女团风 MV，K-pop 韩英混合说唱，1 分 59 秒、98 BPM，从策划做到成片，全部 AI 生成 + 代码剪辑。这里记的是**真实踩过的坑和实际工作量**，给下一支片做策划和排期用。项目文件在用户桌面 `MV/`，项目里的 `CLAUDE.md` 有全部细节。
> 这里的具体数字（BPM、秒数、镜头号）只属于这支片，别当通用规则抄。

---

## 一、做成了什么

- **概念**："四个角落，一条线"——熄了灯的地下二层停车场，四个女孩各守一个角落、各有一种光（荧光冷绿 / 手机闪光冷白 / 车尾灯红 / 昏黄旧灯），地上一条红线把四个角落串起来，副歌时四人走到同一条线上。
- **一人一套造型，全片不换装，换段落靠换光。** 强调色只有一个信号红，每人身上一样红（小红心 / 衣服红线 / 红麦线 / 红镜片墨镜）。
- **86 刀**，分镜计划：L1 代码剪辑 9 刀、L2 静图 16 刀（31 张图）、L3 AI 视频 50 刀、L4 对口型 11 刀；生成单元 53 条。
- **实际**：项目里的生成视频约 200 条（测试、双种子、重跑都算上）；逐刀返修 5 轮；静图刀大多被换成了视频；24 个 3D 重点字 + 42 句普通字幕；最后超分到 1944×1080、加淡水印。

## 二、走了弯路的地方（下次先避开）

| 弯路 | 代价 | 下次怎么做 |
|---|---|---|
| 一开始全是文字方案，用户等不及要看画面 | 用户催"怎么这么慢" | 方向一出就做节奏预览片（示意卡 + 原曲） |
| 先按"世界 1 / 世界 2 换装"做了全套，人物定稿后推翻重来 | 策划、人物、分镜、预览片全部重做一遍 | 人物先定；AI 制作默认一套造型换光 |
| 只问了 BPM，没听出开头结尾的口哨 | 用户提醒才补测 | 策划前先把歌听透（`歌曲结构映射.md` 第五节） |
| 唱段是按歌词内容猜的 | 对口型的刀可能给错人 | 先问真实唱段分配 |
| 想用 30 秒一条拍 12 个镜头省事 | 顺序乱、原曲只跟 2 秒，测试白跑 | 要卡拍、对口型的素材一条一刀，5 秒 |
| 二采精修 + 放大模型 | 画面变脏、人变形，用户以为"画质差" | 只用一采原尺寸，不放大、不加颗粒 |
| 首帧图是半身海报 | 视频前 1.5 秒半身低头闭嘴 | 首帧图按目标景别、动作前姿势出 |
| 近景提示词写了地面 | 三条拉成全身远景，重跑 | 近景不写画面外的东西 |
| 只给空的俯拍场景让模型拍俯拍 | 出成正面全身 | 给一张已经俯拍到人的画面当开场 |
| 没参考视频让 Seedance 按文字跳 | 写"踏步 / two-step"被理解成原地踩，改写后第二版也不行，换 H3 才跳起来 | 有编舞参考就转深度做动作迁移；没有就让 H3"真的在跳" |
| 四段独舞各取一个重拍拼四宫格，放进不到 1 拍的刀 | 用户说"太短还放四个人，不合理"，换掉 | 短刀给单人或局部 |
| 动作迁移提示词只写"严格保持深度视频" | 四条全站桩 | 动作行留一句动作概括 |
| 在缩略图上判断动作 | 白重跑两条 | 放大看脸 |
| 预览片里自制伪 3D 字 | 用户嫌丑 | 预览片只放镜头卡；字幕要做就做真 3D |
| 加水印时重新压缩，码率掉到六成 | 用户发现画质变差 | 码率照原片两遍编码 |
| 用屏幕操控点用户的画布软件 | 用户叫停 | 命令行做不到的请用户手动 |

## 三、用户的口味（这一位用户，做下一支时先确认还是不是这样）

- 要先看到画面再讨论；意见按镜头号一刀刀给，常一次给二十几刀。
- 不要：有人物的升格慢动作、看不懂意思的象征镜头（水滴）、段落中间的黑屏、人像静图长时间不动、同一个人连着几刀、一拍里塞四人群舞、平面花字。
- 要：人物有动势（群众交头接耳、举手机拍）、动作卡在音乐上、动感段落每拍都有事、真 3D 和画面互动的字、画质不比原片差。
- 自己出 MJ 图（用情绪板 `--p` 码精简模式）、自己往画布拖素材；希望我挑图、写理由；说"跑"以后希望我直接提交，不用每条再问。
- 常改主意：一刀可能视频版、静图版来回换，旧版本都要留着。

## 四、管用的办法

- **H3 参考生视频 = 设定图 + MJ 首帧图 + 原曲那 5 秒**：人对、景对、嘴跟原唱（音轨和原曲的音量起伏曲线相关度，用上的在 0.83~0.99）；每条 5 秒约 50 秒出片。
- **舞蹈**：编舞视频截段、对齐 BPM、转深度 → Seedance 2.5 动作迁移（设定图 + 空场景图）。四段单人独舞各补了一刀。
- **已有群舞换机位重拍成正顶俯拍**（视频编辑），比重新编一条俯拍舞成功。
- **镜头号版粗剪 + 一张"每刀怎么改、先剪辑后生成"的安排表**：一轮能改二十几刀，先做不花钱的。
- **素材缺了自动退回占位**的粗剪脚本：任何时候都能从头看到尾。
- **静图 + 代码运动**（快推、残影、红蓝错位）：S53 点名闪切最后定的是这种（视频版用户没要）；S08 则用了视频版。
- **3D 重点字**：抠人 / 深度 + 跟踪 + Blender + 合成，一刀一个文件夹，素材不在时粗剪自动用旧版。
- **一个数据文件生成所有文档**（分镜、镜头表、按人清单）：推翻重来时只改一处。
- 项目里的 `CLAUDE.md` 随时记"做到哪、用哪条、入点多少、为什么"，新开窗口直接接着做。
