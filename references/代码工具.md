# 代码工具：mvfx.py 用法

> `scripts/mvfx.py` 是一个命令行小工具，专做"不用 AI 视频"的那部分活（制作级别 L1、L2，见 `制作方式分级.md`）：
> 闪切、交替、频闪、变色、负片、白闪、故障、冲推、滚转、甩镜、质感层、动态字、画中画、静图慢推、点名重影、按镜头表卡拍剪辑（带镜头号、占位卡）、节奏预览片、舞蹈参考片对齐歌速、截原曲片段。
> 每条命令都用参考片或《Red Line》项目的画面和片段试跑过，并逐帧看过效果。

---

## 一、跑之前

**在哪跑**：你自己电脑上。开始菜单搜"PowerShell"，打开普通窗口就行，不需要管理员。

**第一次用，先装一次依赖**（只装一次）：先输入 `python --version`，能看到 `Python 3.9` 或更高的版本号，说明 Python 已经装好。然后运行：
```
python -m pip install numpy opencv-python Pillow
```
这条命令会从网上下载 3 个 Python 工具包，最后看到 `Successfully installed`（或 `already satisfied`，表示早就装过）就是装好了。另外需要 `ffmpeg`（视频编解码工具）：在窗口里输入 `ffmpeg -version`，能看到版本号就说明已经有了。

**每次用**：先进到素材所在的文件夹，再用脚本的完整路径来调用：
```
cd "D:\你的素材文件夹"
python "<skill 文件夹>\scripts\mvfx.py" beats --bpm 124
```
`<skill 文件夹>` 是这个 skill 装在哪（个人 skill 一般在你用户文件夹下的 `.claude\skills\kpop-mv-production`）。Claude 给你命令时会直接换成实际路径。
下面的例子为了好读，把 `python "...\mvfx.py"` 简写成 `mvfx`。

**看帮助**：`mvfx -h` 列出全部命令；`mvfx montage -h` 看某个命令的全部参数。

**跑完会怎样**：
- 只会新建你用 `-o` 指定的文件，不会改动原素材；
- `-o` 和输入是同一个文件时，脚本会拒绝运行（防止把原素材毁掉）；
- `-o` 指定的文件如果已经存在，会被覆盖。

### 几个词
| 词 | 意思 |
|---|---|
| 帧 / 帧率 | 视频是一张张图连起来的，一张叫一帧；每秒多少张叫帧率（常见 24、30） |
| CSV | 逗号分隔的表格文件，Excel 能打开和另存 |
| 透明通道 | PNG 图片里"哪里透明"的信息；抠好的人就是人以外全透明 |
| 两层视差 | 前景（人）和背景分开移动，前景动得多，看起来有纵深 |
| 动态模糊 | 东西动得快时画面拖出的模糊 |
| 暗角 | 画面四角压暗，像老镜头 |
| 降饱和 | 颜色变淡 |
| 联系表 | 把视频里抽出的很多帧拼成一张图，一眼检查 |

### 通用参数
- `-o 输出.mp4`：输出文件（必填）
- `--size 1280x720`：画面大小。处理单个视频的命令不填就跟原视频一样；`montage`、`kenburns`、`pip`、`assemble` 默认 1280x720；`text` 纯色底时默认 1280x720、叠在视频上时跟视频一样；`interleave`、`whip` 跟 A 素材一样
- `--fps`：帧率。处理单个视频的命令默认跟原视频一样；其余默认 24
- `--bpm 124`：每分钟多少拍。时间写成拍数时需要

### 时间写法（所有时间参数都认）
| 写法 | 意思 | 例子（BPM 124） |
|---|---|---|
| `1.5` | 第 1.5 秒 | 1.5 秒 |
| `4b` | 从**这段素材开头**数过 4 拍的位置 | 1.935 秒（也就是拍位 2.1） |
| `@2.1` | 分镜表里的拍位：第 2 小节第 1 拍（每小节按 4 拍算） | 1.935 秒 |
| `@2.3+` | 第 2 小节第 3 拍的**后半拍** | 3.145 秒 |
| `6f` | 第 6 帧 | 24 帧/秒时是 0.25 秒 |

- 拍数和拍位都从**这段素材的第 0 秒**算起，不是从整首歌开头算。
- 数值是负数时用等号写：`--pan-from=-0.05,0`。
- **在 PowerShell 里，拍位要加英文引号**：写 `--at "@3.1"`、`--at "@1.3,@2.1"`。不加引号，PowerShell 会把 `@` 当成自己的符号直接报错。

## 二、命令一览

| 命令 | 干什么 | 对应手法 |
|---|---|---|
| `beats` | 节拍换算表：每个拍位是第几秒、第几帧 | 写分镜前算拍位 |
| `montage` | 一组图片 / 视频拼成闪切蒙太奇（固定帧数 / 越切越快 / 按拍）；`--ghost` 每张快推 + 残影 + 红蓝错位 | 两帧闪切（T22）、定机位换景（T8）、点名闪切（带重影）、LOGO 环游 |
| `kenburns` | 静图慢推、慢拉、平移；可加抠好的前景做两层视差 | 静图慢推（L2）、极缓推进（Y-M1） |
| `interleave` | 两段素材每 N 帧交替 | AB 交替闪切（T10） |
| `strobe` | 亮 N 帧、暗 M 帧交替 | 明暗频闪（T13） |
| `color` | 每 N 帧换一种颜色 | 色彩频闪（T14）、警灯 |
| `invert` | 指定时间点插几帧负片（颜色反过来） | 负片闪帧（T15） |
| `flash` | 指定时间点白闪 / 黑闪 | 白闪（T11）、黑场（T12） |
| `glitch` | 指定时间点几帧红蓝错位 + 横条错位 | 故障效果 |
| `punch` | 在重拍上猛地放大（带动态模糊） | 快推冲刺（Y-D2） |
| `spin` | 一段时间内把画面转过几度，四角不露黑；能"转出"也能"转入" | 滚转转场（T6）、滚转（Y-D4） |
| `whip` | A 结尾甩出、B 开头甩入 | 甩镜转场（T2） |
| `look` | 暗角 + 降饱和 + 偏色（颗粒默认关，AI 素材别加） | 全片质感层 |
| `text` | 歌词按拍弹出；纯色字卡底色频闪；或叠在视频上 | 动态歌词字、字卡 |
| `pip` | 16:9 黑底中间嵌竖屏手机画面，可轻微手抖 | 竖屏画中画 |
| `assemble` | 读镜头表 CSV，按拍卡点拼成片，可配原曲；`--label` 压镜头号，`--placeholder` 缺素材放占位卡 | 卡点硬切（T1）、整段 / 全片粗剪、镜头号版 |
| `animatic` | 镜头表每刀一张示意卡，跟着原曲卡拍放 | 节奏预览片（策划阶段先看方向） |
| `retime` | 舞蹈参考片放慢 / 加快到歌的 BPM，第 0 秒对齐小节第 1 拍，24 帧，去声 | 编舞参考视频预处理（转深度之前） |
| `cutaudio` | 截原曲片段，可往前多截 | 对口型 / 参考音频 |
| `sheet` | 从视频抽帧拼成一张图（可以逐帧） | 检查效果 |

**声音**：处理单个视频的命令（strobe、color、invert、flash、glitch、punch、spin、look、pip）会保留原视频的声音；`interleave`、`whip`、`kenburns`、`retime` 的输出没有声音；`montage`、`text`、`assemble`、`animatic` 可以用 `--audio` 配音乐（音乐不够长时自动补静音，画面不会被截短）。

**字体**：`text`、`assemble --label`、`animatic` 默认用微软雅黑；文字里有韩文时自动换成带韩文的字体（微软雅黑没有韩文字，会显示成方框）。

## 三、常用例子

### 1. 先算拍位
```
mvfx beats --bpm 124 --bars 8 --start 0.5 --csv 拍位表.csv
```
- 干嘛：第 1 小节第 1 拍在歌里第 0.5 秒，打印 8 个小节每个拍位（含后半拍 `2.3+`）是第几秒、第几帧。
- 得到：屏幕上一张表，另存一份 `拍位表.csv`。
- 怎么找"副歌第一拍在歌里第几秒"：在剪映 / Premiere 里打开原曲，找到副歌第一个重拍，读时间轴上的秒数。`--audio-start` 填的也是这个数。

### 2. 闪切蒙太奇（L2 + L1）
```
mvfx montage --dir .\LOGO地标图 --frames 2 -o LOGO环游.mp4
mvfx montage --dir .\点名特写 --accel 9:5 -o 点名闪切.mp4
mvfx montage a.jpg b.jpg c.jpg d.jpg --beats 0.5 --bpm 124 --drift 0.03 --audio 歌.mp3 --audio-start 45.2 -o 半拍闪切.mp4
```
- `--frames 2`：每张 2 帧（小红书预告的 LOGO 环游就是这样）。12 张图得到约 1 秒、1280x720 的无声视频。
- `--accel 9:5`：从每张 9 帧逐渐缩到 5 帧（aespa《LEMONADE》点名闪切的节奏）。
- `--beats 0.5`：每张半拍，按累计时间取整，长了也不会越剪越偏。
- `--drift 0.03`：每张图内部轻微推近 3%，静图也有一点"活"。
- 文件夹里的文件按"数字大小"排序：2.jpg 排在 10.jpg 前面。

### 3. 静图慢推（L2）
```
mvfx kenburns 太空舱大远景.png --dur 3 --zoom-from 1.0 --zoom-to 1.12 -o 慢推.mp4
mvfx kenburns 太空舱大远景.png --dur 3 --zoom-from 1.15 --zoom-to 1.0 -o 慢拉.mp4
mvfx kenburns 背景.png --fg 成员抠图.png --dur 2.5 --zoom-to 1.08 -o 两层视差.mp4
```
- 得到：一段 3 秒、无声的视频，画面慢慢放大（或缩小）。
- 放大倍数不能小于 1；慢拉就把 `--zoom-from` 写大、`--zoom-to` 写 1.0。
- `--pan-from / --pan-to`：起止中心偏移（画面比例），比如 `--pan-to 0.05,0` 是边推边往右移。移得太多会自动收住，想移得多就把 `--zoom-to` 调大。
- `--fg`：前景要是**和背景图一样大**的透明 PNG（整幅画面大小、人以外的地方透明）。前景比背景动得多，产生纵深感（`--fg-mult` 调倍数）。
- 提醒：空镜慢推控制在 2~3 秒以内、人像控制在半拍以内，再长就会显得假（人一动不动）。人像要有眨眼、发丝动的，就用 AI 视频。

### 4. AB 交替闪切
```
mvfx interleave --a 伸手.mp4 --b 无限符号.mp4 --every 3 --dur 25f -o L1_S05_AB交替.mp4
```
- 干嘛：两条素材都按时间连续往下走（伸手的动作是连贯的），只是每 3 帧换一次画面。
- 得到：25 帧（约 1 秒）的无声视频，大小跟 A 素材一样。BPM 124 时 2 拍约 23~24 帧，故意多做 1~2 帧：放进镜头表 2 拍那一刀时，多出来的会被自动截掉，不会定格。

### 5. 频闪 / 变色 / 负片 / 白闪 / 故障 / 冲推 / 滚转
```
mvfx strobe 俯拍.png --dur 1.5 --on 3 --off 2 -o 心跳频闪.mp4
mvfx color 夜街.mp4 --colors red,blue --every 3 --strength 0.4 -o 警灯.mp4
mvfx invert 群舞.mp4 --at 1.0 --frames 2 -o 负片.mp4
mvfx flash 副歌.mp4 --at "@3.1" --bpm 124 --frames 5 --hold 2 -o 白闪.mp4
mvfx glitch 人像.mp4 --at 0.5,1.5 --frames 3 -o 故障.mp4
mvfx punch 群舞.mp4 --at "@1.3,@2.1" --bpm 124 --scale 1.2 -o 冲推.mp4
mvfx spin A段.mp4 --deg 90 --start 1.6 --length 0.4 --ease in -o 转出.mp4
mvfx spin B段.mp4 --from-deg -90 --deg 0 --start 0 --length 0.4 --ease out -o 转入.mp4
```
- 得到：和输入一样长、一样大小、一样帧率的视频，保留原声音，只在指定位置加了效果。
- 输入是图片时必须加 `--dur`（做几秒）。
- `--at` 超过视频长度时会提示"不会生效"。
- `flash --color black` 就是黑场。
- `punch` 默认一次比一次近（累计推近）；加 `--reset` 每次都从原大小推。
- `spin`：转出用 `--ease in`（越转越快），转入用 `--from-deg -90 --deg 0 --ease out`（从斜着转回正）。转 90° 时画面要放大约 1.8 倍盖住四角，清晰度会掉，有人物的镜头尽量只转小角度。

### 6. 甩镜转场
```
mvfx whip --a 拳击馆.mp4 --b 夜街.mp4 --dur-a 1.2 --dur-b 1.2 --frames 5 --dir right -o 甩镜.mp4
```
- 干嘛：A 的最后 5 帧加速甩出、B 的前 5 帧从模糊里甩进来停稳。`--dir` 是镜头往哪边甩。
- 得到：约 2.4 秒的无声视频，大小跟 A 一样。

### 7. 质感层（全片统一）
```
mvfx look 粗剪.mp4 --vignette 0.45 --sat 0.85 --tint teal --tint-strength 0.08 -o 粗剪_质感.mp4
```
- 干嘛：加暗角、降饱和、偏色（`--tint none` 不偏色）。**颗粒默认不加**：AI 生成的素材本身就有颗粒，再加会显脏（实测用户嫌"画质差"）。实拍或很干净的 CG 素材才加 `--grain 0.05`。
- 得到：和输入一样长的视频，**保留原声音**。先拿一小段试，用户认可了再整片跑。

### 8. 动态歌词字 / 字卡
```
mvfx text --words "did,that,what's,next" --bpm 124 --each 1 --bg red -o 逐词弹出.mp4
mvfx text --words "I,don't,fit,the,criteria" --bpm 124 --each 0.5 --mode one --bg white,mint,black,red,orange --every 2 -o 字卡频闪.mp4
mvfx text --words "无限,∞,INFINITY" --bpm 124 --each 1 --input 素材.mp4 -o 叠字.mp4
```
- `--mode pop`（默认）：词一个个弹出、留在画面上，从上到下阶梯排开、左右交错、越来越大（Keyveatz 的做法）。
- `--mode one`：一次只显示一个大字。
- `--bg` 写多个颜色，底色每 `--every` 帧换一次。
- `--color auto`（默认）：按底色自动选黑字或白字；叠在视频上时用白字黑描边。
- 中文默认用微软雅黑粗体；换字体用 `--font 字体文件路径`（路径写错会提示）。
- 词里本身有逗号时，改用 `|` 分隔：`--words "Hello, world|next"`。
- 得到：一段无声视频（可用 `--audio` 配音乐），字不会出画面。

### 9. 竖屏画中画
```
mvfx pip 手机素材.mp4 --dur 1.5 --shake 0.01 -o 竖屏画中画.mp4
```
得到：1.5 秒、1280x720 的视频，黑底中间一个竖屏小画面，轻微手抖。

### 10. 按镜头表剪辑（把分镜表直接剪成片）

先准备一个 CSV（可以用 Excel 编辑，另存时选"CSV UTF-8（逗号分隔）"；选普通"CSV（逗号分隔）"也能读）：
```
镜头,素材,入点,长度,效果
S01,U01_黄舱群舞.mp4,0.5,4拍,
S02,P03_成员A眼睛.png,0,0.5拍,白闪2
S03,P04_成员B眼睛.png,0,半拍,
S04,U02_成员A近景.mp4,1.2,1拍,冲推
S05,L1_S05_AB交替.mp4,0,2拍,
S06,U04_无限符号.mp4,0,2拍,推近+故障3
```
```
mvfx assemble 镜头表.csv --bpm 124 --audio 歌.mp3 --audio-start 45.2 -o 副歌1粗剪.mp4
```

**分镜表 ① 怎么转成这张表**：
| CSV 列 | 从分镜表哪里抄 | 写法 |
|---|---|---|
| 镜头 | S 编号 | S01 |
| 素材 | "来自"那一列对应的文件 | 视频或图片；相对路径以 CSV 所在文件夹为准 |
| 入点 | "来自"里写的起始秒 | 从素材第几秒开始用；图片写 0 |
| 长度 | "时长"那一列 | `4拍` / `0.5拍` / `半拍` / `6帧` / `0.93秒`；照抄"4 拍 / 1.88 秒"也行，只取斜杠前面 |
| 效果 | "动效"里能在这里做的 | 只认 6 种，可用 `+` 连：白闪2（开头 2 帧白，写 白闪4 就是 4 帧）、黑闪2（开头 2 帧黑）、负片 / 故障（不写数字是**整刀**都加；写 负片2、故障3 就只加开头 2、3 帧）、冲推（开头 3 帧推近）、推近（整刀轻微推近 6%）。英文写法 white2 / black2 / invert / glitch / punch / push 也认 |

- 每刀的帧数按**累计时间**取整，剪一整首也不会越剪越偏离节拍。
- 跑完会打印每一刀实际用了多少帧、取自哪个素材；素材不够长时会写"注意：最后 N 帧是定格"。
- **别的效果**（甩镜、滚转、AB 交替、字卡、频闪……）先用前面的命令单独做成小视频，再当素材放进镜头表。小视频建议命名为 `L1_S几_说明.mp4`（例：`L1_S05_AB交替.mp4`），镜头表"素材"直接填这个名字。单独做的小视频要比镜头表里的长度**多 1~2 帧**，不然最后一帧会定格。
- 一行比表头多出格子（比如效果之间用了逗号）会在开剪前报出来。mp4 / mov 没下载完或没拷完、而且这一刀正好用到了缺的那段，也会在开剪前报出来；mkv / webm 查不出是否完整，只会提示"最后 N 帧是定格"。
- 长度写成 0、负数、超过 600 秒会报错；短到不足 1 帧的刀会被跳过并提示。
- 遇到坏文件时，屏幕上可能多出几行 `[h264 @ …]`、`moov atom not found` 这样的英文，是视频解码库自己打的，看"出错了"或"注意"开头的那行中文就行。
- 全角字符（输入法打出的 ／ ＋ ２）会自动换成半角（素材文件名除外，原样保留）；素材找不到、效果写错，会在**开始剪之前**就报出是第几行哪一刀，不会留下坏文件。
- 表头要正好是 `镜头,素材,入点,长度,效果`；空行会自动跳过；写错时会用中文告诉你第几行、哪里错。

**镜头号版和占位卡**（流程 D 每次出粗剪都出两版）：
```
mvfx assemble 镜头表.csv --bpm 98 --audio 歌.mp3 --audio-start 0 --placeholder -o 全片粗剪.mp4
mvfx assemble 镜头表.csv --bpm 98 --audio 歌.mp3 --audio-start 0 --placeholder --label -o 全片粗剪_镜头号.mp4
```
- `--label`：每刀左下角压"镜头号 + 这刀在歌里第几秒开始"，用户看片时按号说改哪刀。秒数从 `--audio-start` 算起（只剪一段时也对得上整首歌的时间）；要从别的数算用 `--label-start`。**成片别加。**
- `--placeholder`：素材还没生成的刀不报错，放一张深灰占位卡（镜头号 + 镜头表"画面"列 + 缺哪个文件），整片照样能从头看到尾；跑完会列出哪几刀是占位。
- 镜头表可以多加一列"画面"（这刀拍什么），占位卡上会显示。

### 11. 节奏预览片（策划阶段，还没有素材时）
```
mvfx animatic 预览表.csv --bpm 98 --audio 歌.mp3 --audio-start 0 --beat0 1.434 -o 节奏预览片.mp4
```
- 预览表至少要有 `镜头,长度` 两列；可以再加 `画面`（卡片中间的说明）、`歌词`（卡片下方，黄字）、`世界`（同一个世界同一种底色）或 `颜色`（直接写颜色名或 #RRGGBB）、`制作`（L1~L4，显示在镜头号旁边）。
- `--audio-start`：第一刀在歌里第几秒（整首从头做就写 0）。`--beat0`：歌里第 1 小节第 1 拍的秒数（有弱起的歌要给），每拍开头卡片闪亮一下、右下角小圆点数拍子，都按它对齐。
- 每张卡左下角是这刀在歌里第几秒开始。预览片只放卡片和简单歌词，**别做花哨字效**。

### 12. 舞蹈参考片对齐歌速
```
mvfx retime 编舞原片.mp4 --src-bpm 103 --bpm 98 --from 144.34 --dur 5 -o U27_四人副歌_98BPM_5秒.mp4
```
- `--src-bpm` 原片的 BPM，`--bpm` 歌的 BPM，`--from` 原片里小节第 1 拍的秒数，`--dur` 要几秒。
- 得到：24 帧、没有声音的视频，动作的一拍正好等于歌的一拍，第 0 秒就是小节第 1 拍。之后转深度视频、给动作迁移用；剪辑时入点取一拍的整数倍就卡在拍上。
- 放慢很多（比如 0.8 倍以下）觉得卡，可以加 `--blend`（相邻两帧混合，快动作会有重影）。

### 13. 截原曲片段（对口型 / 参考音频）
```
mvfx cutaudio 歌.mp3 --start 76.13 --dur 5 --lead 2.4 -o U35_原曲.wav
mvfx cutaudio 歌.mp3 --start "@11.1" --bpm 98 --bar1 1.434 --dur 5 -o S17_原曲.wav
```
- `--start` 要的那句在歌里第几秒；`--lead` 往前多截几秒（想让这句唱在推近以后，就让它落在片段第 2~3 秒）。
- `--start` 按拍位写时，要用 `--bar1` 写歌里第 1 小节第 1 拍的秒数（有弱起的歌不给会差几拍）。
- 跑完会打印"歌里第几秒 = 起点 + 素材第几秒"，挑入点时照这个换算。

### 14. 点名重影（静图快切加剪辑运动）
```
mvfx montage C.png A.png B.png D.png --beats 0.5 --bpm 98 --ghost --push 0.08 --push-last 0.14 --centers "0.5,0.22;0.46,0.21;0.46,0.17;0.29,0.19" --size 1152x640 -o L1_S53_点名重影.mp4
```
- 每张一切进来往 `--centers`（脸的位置，画面比例 x,y）快推 `--push`（先快后慢，头几帧带运动模糊）；最后一张可以推得更多（`--push-last`）当收尾重音。
- 上一张继续放大、变淡留 3 帧残影，新的一张带一层大一圈的虚影 3 帧收回；残影只叠比底图亮的地方，暗部不会发灰。每切第一帧红蓝错位、第二帧减半。
- 《Red Line》S53 最后定的就是这种做法。帧数按 `--beats` 累计取整，和项目里按歌的绝对帧切出来的可能差一帧（项目是 8/7/8/7，这里是 7/8/7/7）。

### 15. 检查效果
```
mvfx sheet 副歌1粗剪.mp4 --count 24 --cols 6 -o 检查.jpg
mvfx sheet 副歌1粗剪.mp4 --every-frame --start 0.8 --end 1.3 --cols 12 -o 逐帧检查.jpg
```
- 第一条：均匀抽 24 帧拼成一张图，看整体有没有错位、字有没有出画面。
- 第二条：把 0.8~1.3 秒**每一帧**都排出来，每格标"#帧号 秒数"。检查 2 帧白闪、每 3 帧交替这种短效果要用这个——均匀抽帧很容易正好漏掉。

## 四、mvfx 没包含的，用这些

**分屏（左边人、右边字卡）**：在同一个 PowerShell 窗口里，先把字卡做成**半边大小**（640x720），不然右边的字会被裁掉：
```
mvfx text --words "I,don't,fit" --bpm 124 --each 0.5 --mode one --bg white,mint,black --size 640x720 -o 字卡_半边.mp4
```
再左右拼起来：
```
ffmpeg -i 人像.mp4 -i 字卡_半边.mp4 -filter_complex "[0:v]fps=24,scale=-2:720,crop=640:720[l];[1:v]fps=24,scale=-2:720,crop=640:720[r];[l][r]hstack=shortest=1" -an -c:v libx264 -pix_fmt yuv420p 分屏.mp4
```
- 干嘛：把两段都统一成 24 帧/秒、缩到 720 高，各裁成半边（640 宽），左右拼起来；`-an` 表示不要声音。
- 得到：1280x720、长度跟短的那条一样、没有声音的 `分屏.mp4`。

**黑白高反差**：
```
ffmpeg -i 素材.mp4 -vf "hue=s=0,eq=contrast=1.6:brightness=-0.05" -c:v libx264 -pix_fmt yuv420p -c:a copy 黑白.mp4
```
- 干嘛：去掉颜色（`hue=s=0`），对比度拉到 1.6 倍，稍微压暗。
- 得到：一样长、保留声音的黑白视频。

**用剪辑软件做的**：片头片尾 LOGO 动画、监视器 UI、HUD 数据标签、半调网点、碎镜，用 After Effects 或剪映的模板 / 插件。

**后期减速**：先用剪辑软件的"光流补帧"（让软件在两帧之间算出中间帧）再减速，否则会一卡一卡。
