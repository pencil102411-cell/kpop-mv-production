# 动效与质感库（画面上的"效果层"）

> 动效 = 画面上额外加的东西：字、LOGO、界面、颗粒、闪烁、风格滤镜、物件特效。
> 每条标了 **【AI】**（适合让 AI 视频直接生成）或 **【后期】**（用后期软件做，比如 After Effects、剪映、Premiere，AI 别碰）。
> 对应制作级别：【AI】＝可以写进 AI 生成提示词（一般是 L3；在已有视频上换画风的是 L4；只是静帧 + 快切的是 L2）；【后期】＝ L1。每一项最终用哪一级、用哪个 `mvfx` 命令，以 `references/制作方式分级.md` 为准。
> **原则：凡是"文字""精确节奏的闪烁""界面 UI"都放后期**——AI 写字会错、闪烁不准、界面会糊。

## 一、文字与 LOGO

> **歌词字幕和 3D 重点字的具体做法见 `references/字幕与重点字.md`。** 实战教训：自己用代码拼的"伪 3D"（字立牌一样翻起、斜着摆、挤出厚度）用户嫌丑；平面动效（逐词弹出、模糊浮现）用户嫌"低级"；用户认可的是真 3D 渲染、和画面有遮挡和光影互动的字。下表的平面字卡手法适合杂志感、快切字卡这类本来就是平面设计的地方。

| 效果 | 样子 | 出处 | 做法 |
|---|---|---|---|
| 动态歌词字（kinetic typography） | 歌词单词一个个弹出来，越来越大，落在节拍上 | KV「did / that / what's / next」 | 【后期】 |
| 杂志排版字卡 | 大红满屏 + 粗黑团名 + 密排小字歌词 | KV 段落开头 | 【后期】 |
| 手写体↔印刷体切换 | 同一句歌词在几帧内换字体 | KV「know better」 | 【后期】 |
| 分屏歌词卡 | 左边人唱，右边满屏歌词，底色 2 帧一换 | KV 说唱段 | 【后期】，人像部分【AI】 |
| 大字母拼团名 | 黑底小方窗 + 巨大蓝色字母 U / N / A，一个镜头一个字母 | UNA | 【后期】，方窗里的画面【AI】 |
| 3D 铬金属 LOGO 闪现 | 金属涂鸦 LOGO 出现在世界各地地标上，每处 2 帧 | XHS | 背景地标【AI】，LOGO【后期 3D】 |
| LOGO 材质轮换 | 团名变成金属牙套、铬金属、钻石链、蕾丝，每个 0.17 秒 | KV | 【AI 图像】出静帧，后期快切 |
| 片尾 LOGO 动画 | 黑底荧光字：歌名字体 → 团标 → 公司标 | LEMON、SHAKIN、HitEm | 【后期】 |
| 片尾字幕叠在长镜上 | 演职员表叠在一镜到底的画面上 | KV 片尾 8~11 秒长镜 | 画面【AI】，字【后期】 |
| 底部双语小字幕 | 中英歌词小字一直在画面下方 | UNA | 【后期】 |
| 综艺花字 | 韩综式彩色字+表情（What???） | SHAKIN 幕后段 | 【后期】 |

## 三、质感层（整支片的"滤镜"）

> AI 生成的素材本身已经有颗粒，整片再加颗粒会显脏；先看素材，需要时只加暗角、调色，颗粒默认关掉。

| 质感 | 样子 | 出处 | 提示词 / 做法 |
|---|---|---|---|
| 胶片颗粒 + 圆形暗角 | 低饱和青灰、颗粒明显、四角发黑像老镜头 | HitEm 全片 | 【AI】`35mm 胶片质感，细腻颗粒，四角明显暗角，低饱和青灰色调`；【后期】加强 |
| 半调网点（印刷网点） | 黑白画面里放大的网点纹理 | KV 开场 | 【后期】网点滤镜 |
| 黑白高反差 | 纯黑纯白，几乎没有灰 | KV 多段 | 【AI】`黑白高反差摄影` 或【后期】 |
| 粒子点阵人像 | 人脸由发光颗粒组成，带数据标签 | KV | 【AI】可尝试；稳定性一般 |
| 漫画线稿化 | 真人变黑白赛璐珞漫画，白色高光勾边 | SHAKIN | L4 视频转视频风格化（把已有视频整体换成漫画画风） |
| 夜视绿 | 整个画面绿色单色+噪点，像夜视仪 | SHAKIN 结尾 | 【AI】`夜视仪绿色单色画面，噪点明显`；或【后期】调色 |
| 鱼眼 / 球面反射 | 画面四周弯曲，人在球面里 | UNA、LEMON | 【AI】`鱼眼镜头畸变` |
| 数字撕裂故障 | 脸部横向错位撕裂几帧 | UNA 圆框人像 | 【后期】故障特效插件（glitch） |

## 用法规则
1. **一支片只选 1 套质感层**（比如"胶片颗粒+暗角"或"冷蓝 CG 光洁"），全片统一。质感层写进**每一条**提示词的风格段，保证镜头之间统一。
2. 文字类动效**一律放后期**，分镜里写"【后期字卡】内容：xxx，出现方式：逐词弹出，卡第 N 拍"。
3. 物件特效镜头（液体、玻璃、主题物件）是**AI 成功率最高、最出效果**的镜头，可以多用来填快切蒙太奇和段落换气。
4. 分镜表里每一刀标制作级别 L1~L4（只表示画面从哪来）；叠在上面的动效写在"动效"列，归入代码与剪辑清单。
