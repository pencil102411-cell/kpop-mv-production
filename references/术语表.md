# 术语表：第一次出现照这个解释

> 用户要求白话（见全局沟通规则）。表格可以用，但每格写人话；专业词第一次出现时括号解释。用户可能要拿去搜索或跟同事沟通的词，白话后面补上专业说法。


| 词 | 白话 |
|---|---|
| 母题 | 反复出现、让人记住这首歌的物件或符号 |
| 世界 | 一套场景 + 主色 + 光线（+ 服装），换世界就整套换 |
| 强调色 | 全片每个世界都出现的那一种颜色，把所有世界串起来 |
| 能量曲线 | 全片每一段热闹、刺激程度的高低起伏 |
| 招牌镜头 | 能截图当封面、别的 MV 没有的画面 |
| S / 剪辑镜头 | 成片里观众看到的一刀 |
| U / 生成单元 | AI 实际生成的一条视频，一条能剪出好几刀 |
| BPM | 每分钟多少拍 |
| 弱起 | 歌在第一个重拍之前先进来的那几拍 |
| 拍位 | 写成"小节.拍"，比如 2.1 是第 2 小节第 1 拍，2.3+ 是第 2 小节第 3 拍的后半拍 |
| 重拍 / 卡点 | 音乐里最用力的那一下鼓点 / 剪辑点落在鼓点上 |
| 节奏预览片 | 还没有真素材时，用示意卡跟着原曲卡拍放的小样，先看节奏和方向 |
| 设定图 / 定妆图 | 成员造型的标准参考图（脸部特写 + 正背侧全身），AI 照着它画人 |
| 首帧图 | 给视频模型的开场画面：首帧生视频里它就是第一帧，参考生视频里模型也会照它的构图开场 |
| 文生 / 图生 / 首帧生视频 | 只给文字 / 给一张图当第一帧让它动起来 |
| 参考生视频 | 给几张参考图（人、场景、首帧图）、文字和音频，让模型自己拍 |
| 音轨和原曲像不像（包络相关） | 把两条音轨的音量起伏画成曲线比一比，1 = 一模一样；用来判断生成视频是不是照着原曲在唱 |
| 两遍编码 / crf | 编码器先看一遍整片、第二遍按指定码率分配画质 / 按固定质量编码，数越小画质越高 |
| 特征点跟踪 | 在画面里找一批好认的小点，逐帧看它们怎么挪，算出镜头或地面怎么动 |
| 滤色叠加（screen） | 一种把两层画面叠亮的混合方式；暗部会被抬灰 |
| 首尾帧 | 给开头和结尾两张图，让 AI 补中间 |
| 参考视频驱动 / 动作迁移 | 给一段真人跳舞视频（常先转成只有深浅的"深度视频"），让 AI 照着动作做，换人换背景 |
| 种子 | 同一条提示词换个随机数再跑一次，结果会不一样 |
| 入点 | 这一刀从素材的第几秒开始用 |
| 一采 / 二采 | 生成的第一遍 / 在第一遍上再细化一遍 |
| 超分 | 用软件把视频放大到更高分辨率并补细节 |
| 码率 | 每秒视频用多少数据，越低画质越差 |
| 抠像 | 把人从背景里分离出来 |
| 镜头号版 | 每刀左下角压着镜头号的粗剪，方便按号说改哪刀 |
| 人物锚点短句 / 质感层短句 | 每条提示词都原样复制的一句人物描述 / 画面风格描述 |
| 锚点镜头 | 让观众看清整段编舞的那个稳定镜头 |
| 对口型 | 让画面里的嘴型和真实歌声对上 |
| 降级 | AI 做不好时，换一种更容易做的拍法（比如群舞改剪影） |
| 跳切 | 两刀画面太像，看起来像画面抖了一下 |
| 升格 | 高帧率拍，放出来是慢动作 |
| 穿帮 | 画面里出现不合理、一看就假的地方 |
| C 位 | 站在正中、最突出的位置 |
| L1~L4 | 制作级别：代码剪辑 / 静图加代码 / AI 视频 / 视频编辑 |
| 静图慢推 / 两层视差 | 图片用代码慢慢放大平移 / 前景和背景分开移动，看起来有纵深 |
| 闪切 / AB 交替 | 一刀只有几帧的连续快切 / 两个画面每几帧来回切 |
| 白闪 / 黑场 / 频闪 / 负片 | 画面突然变白 / 变黑几帧 / 明暗或颜色每几帧来回跳 / 颜色整个反过来 |
| 粗剪 / 镜头表 | 先按音乐把镜头大致拼起来的版本 / 每行一刀的表格（CSV，Excel 能打开） |
| 快切蒙太奇 | 一串很短的镜头快速连切，拼出一个意思 |
| 景别 | 画面里人占多大：大远景、全景、中景、近景、特写、极近 |
| 运镜 / 甩镜 / 滚转 | 镜头怎么动 / 快速横甩糊成横条 / 画面绕中心转起来 |
| 转场 | 从一个镜头换到下一个镜头的方式 |
| 剪影 | 人站在亮背景前，只看得到黑色轮廓 |
| 字卡 / 3D 重点字 | 画面上的文字画面 / 放进镜头空间、和人有遮挡和光影关系的立体字 |
| 质感层 | 全片统一的画面风格，比如胶片颗粒加暗角 |
