# 制作方式分级：每一刀用什么做

> **结论：能用便宜、好控制的办法做，就不用 AI 视频。**
> 分镜表里每一刀都要标一个制作级别 L1~L4。先看能不能从已经要生成的视频里截（复用），再想 L1、L2，最后才新增 L3。

---

## 一、为什么要分级（来自 6 支参考片的数据）

- 781 个镜头里，**33% 短于 0.3 秒**：如果本来就是从某条 AI 视频里截的（比如 AB 交替、甩头的一瞬），照截就行；只有单独一张脸、一个物件、一个地标这类，才换成静图；
- 另有 **11%** 摄影机几乎没动——但画面里的人可能在跳舞（例：HitEm 第 16 镜摄影机不动，5 人在跳群舞），要逐个看；
- 所以"不需要 AI 视频"的刀**上限约 44%**（Keyveatz 上限约 60%），实际会更少；
- 但**按时长只占 6%~18%**——观众看到的大部分时间，仍是人在跳、在甩头、镜头在空间里动，这些还得靠 AI 视频。

所以：分级能**大幅减少 AI 视频生成条数**，但舞蹈、人体动作、真实空间运镜这些最重的活还是 L3。

---

## 二、四个级别

| 级别 | 是什么 | 用什么做 | 成本 | 可控性 |
|---|---|---|---|---|
| **L1 代码 / 剪辑** | 不需要新画面，只对已有画面做剪辑和效果 | `scripts/mvfx.py`（见 `references/代码工具.md`）、ffmpeg、剪映、After Effects、Premiere | 几乎为零 | 最高：帧级精确，能卡拍 |
| **L2 静图 + 代码动起来** | 先用图像模型出图，再用代码做慢推、平移、两层视差、闪切 | 图像模型出图 + `mvfx.py kenburns / montage` | 低 | 高：构图、光线一张张可控 |
| **L3 AI 视频生成** | 画面里有"真实的动"：人体动作、物理现象、空间运镜 | Seedance 等视频模型（文生 / 图生 / 首尾帧 / 参考视频驱动） | 高，常要重做 | 中低 |
| **L4 视频编辑 / 风格化** | 已有视频，在上面改 | 视频编辑模型、抠像、风格化、对口型工具 | 中 | 中 |

> 几个词：**文生**＝只给文字；**图生**＝给一张图让它动起来；**首尾帧**＝给开头、结尾两张图，让 AI 补中间；**参考视频驱动**＝给一段真人动作视频，让 AI 照着动作做；**抠像**＝把人从背景里分离出来；**两层视差**＝前景和背景分开移动，看起来有纵深；**图像编辑**＝在已有图片上改局部（换内容、加 LOGO），构图和光线不变。

### 怎么判断（按顺序问）
0. 这一刀能从**已经要生成的某条 U 里截出来**？→ 标 **L3**（注明复用 U 几），不增加生成量
1. 这一刀**只是对别的画面做效果或剪接**（闪、交替、频闪、变色、字、甩镜、旋转、推近）？→ **L1**
2. 这一刀是**单独一张脸、一个物件、一个地标或空镜**，而且**画面里没有东西在真实地动**（只需要镜头轻微推拉平移；短于 0.3 秒的刀观众基本看不出动没动）？→ **L2**
3. 画面里**有人在动 / 有物理现象 / 镜头在真实空间里穿行**？→ **L3**
4. **已经有一段视频**，要换背景、换画风、对口型？→ **L4**

> **唱段对口型**：把这一句歌声直接喂给模型、一起生成的，算 **L3**；先生成画面、再用对口型工具改嘴的，算 **L4**。

### L2 的边界（别用过头）
- 静图慢推：**空镜 2~3 秒以内、人像半拍以内**，再长就会显得假（人一动不动）。人像要有眨眼、发丝飘、呼吸感，就得 L3。实战里用户把 1 拍以上的人像静图（毛衣微距、人群背影、远景、绿灯下的人群）几乎全换成了视频。
- **静图一定要带代码运动**：只是硬切的静图容易显得死（S53 用户就要求"加镜头运动或重影"）。半拍一张的点名闪切，最后定下来的是：每人切进来往脸上快推 8%~14%（先快后慢、头几帧带运动模糊）、上一个人放大变淡留 3 帧残影、新人带一层大一圈的虚影收回、切点第一帧红蓝错位（`mvfx montage --ghost`）。实战里两种结果都有：S53 这四张先跑成了视频，用户看完换回静图、再要求加剪辑运动，定了这版；S08 那四张点名特写跑成视频后一直在用。拿不准时两种都给用户看。
- 残影叠加用"只叠比底图亮的地方"，不要用"滤色"叠加（screen，一种把两层画面叠亮的混合方式，会把暗部抬灰、像起雾）。
- 两层视差（`kenburns --fg`）要先把人抠成透明 PNG；抠得不干净，边缘会露馅。
- L2 的图也要守一致性：同一世界用同一组定妆图、同一套光线描述出图（用户需要的话，可以建议用 `character-scene-asset-prompt` 写图像提示词）。

## 三、库里每个手法该用哪一级

> 表里写"L2 + L1"的意思是：画面用 L2 做（"制作"列填 L2），效果用 L1 做（写在"动效"列，进代码与剪辑清单）。写"效果 L1"的，画面本身另算——如果要专门生成，那条 U 要列进生成单元清单。

### 转场库
| 手法 | 级别 | 怎么做 |
|---|---|---|
| T1 卡点硬切 | L1 | `mvfx assemble`（按镜头表卡拍剪） |
| T22 两帧闪切蒙太奇 | L2 + L1 | 出一组图 → `mvfx montage --frames 2`（或 `--accel 9:3` 越切越快） |
| T2 甩镜转场 | 效果 L1 | `mvfx whip`；A、B 两段画面按各自来源另算 |
| T3 身体 / 头发遮挡擦除 | L3 | 需要真实的甩发、身体扫过镜头 |
| T4 推穿物体 / T5 穿洞 | L3（首尾帧） | 便宜替代：两张图各 `kenburns` 推到洞口填满 + 硬切或白闪 |
| T6 滚转转场 | 效果 L1 | `mvfx spin`（自动放大盖住黑角；转入用 `--from-deg -90 --deg 0 --ease out`） |
| T7 冲进烟尘 / 光球 | L3 + L1 | 冲进去用 L3，画面被填满处接 `mvfx flash` |
| T8 定机位换景闪切 | L2 + L1 | 同一张空场景底图，用图像编辑换内容出 6~12 张 → `mvfx montage --frames 4` |
| T9 同人同姿换背景 | L2 或 L4 + L1 | 静帧版：同一人像图换背景出多张；动态版：抠像换背景 → `montage` / `assemble` 交替 |
| T10 AB 交替闪切 | 效果 L1 | `mvfx interleave --every 3`；两条素材通常是 L3（至少一条要是连续动作），算进 U |
| T11 白闪 / T12 黑场 | L1 | `mvfx flash`（`--color black` 是黑场），或镜头表效果写 `white2` / `black2` |
| T13 明暗频闪 | L1 | `mvfx strobe` |
| T14 色彩频闪 | L1 | `mvfx color` |
| T15 负片闪帧 | 效果 L1 | `mvfx invert`，或镜头表效果写 `负片2`（只闪 2 帧；不写数字是整刀负片） |
| T16 碎镜 | L3 或 L1 插件 | AI 生成碎裂，或剪辑软件的碎裂特效插件 |
| T17 液体 / 墨水绽放 | L3 | AI 很擅长 |
| T18 材质 / 风格切换 | L4 | 视频转视频风格化（把已有视频整体换成漫画、黑白等画风） |
| T19 门开合 | L3 | |
| T20 物件 / 列车掠过 | L3（或 L1 `whip` 近似） | |
| T21 手掌盖镜头 | L3 | |

### 动效与质感库
| 效果 | 级别 | 怎么做 |
|---|---|---|
| 动态歌词字、满屏字卡、字卡底色频闪 | L1 | `mvfx text`（`--mode pop` 逐词阶梯排开；`--mode one` 一次一个大字；`--bg` 写多个颜色就会频闪） |
| 分屏（左人右字） | 效果 L1 | 字卡用 `mvfx text`，再用 ffmpeg 左右拼（命令见代码工具）；人像素材通常是 L3，算进 U |
| 竖屏画中画 | 效果 L1 | `mvfx pip`；里面的画面按来源另算 |
| 颗粒 + 暗角 + 降饱和 + 偏色 | L1 | `mvfx look`（全片统一质感层） |
| 故障效果 | 效果 L1 | `mvfx glitch`，或镜头表效果写 `故障3`（只做开头 3 帧；不写数字是整刀） |
| 卡点冲推 | 效果 L1 | `mvfx punch`，或镜头表效果写 `冲推` |
| 黑白高反差 | L1 | ffmpeg 调色（命令见代码工具） |
| LOGO 环游世界 | L2 + L1 | 地标空镜图（图像模型出图，LOGO 用图像编辑放进去或后期贴）→ `montage --frames 2` |
| LOGO 材质轮换 | L2 + L1 | 每种材质一张图 → `montage` |
| 片头片尾 LOGO 动画、监视器 UI、HUD 数据标签、半调网点 | L1（剪辑软件） | After Effects / 剪映模板；`mvfx` 暂不包含 |
| 物件特效（液体、玻璃泡、柠檬落水） | L3 | AI 视频最稳的一类 |

### 构图 / 运镜里适合 L2 的
| 手法 | 级别 | 怎么做 |
|---|---|---|
| Y-M1 极缓推进 | 空镜 L2；人像半拍以内 L2，更长用 L3 | `kenburns --zoom-to 1.08~1.15`。人像慢推超过半拍，没有眨眼、发丝动就会显得假 |
| C2 尺度反差大远景（空间里一个小人） | L2 | 出图 + `kenburns` 慢推 |
| B1 极近五官裁切（0.1~0.3 秒一刀） | 静止的 L2；眼睛睁开、眨眼等有动作的 L3（或从已有 U 里截） | 每人一张极近特写图 → `montage` 或镜头表 |
| 点名闪切（每人一张静态特写） | L2 | 同上，`montage --accel 9:5` 做出越切越快；要带推镜和重影用 `montage --ghost` |
| D1 剪影（摆造型不跳舞） | L2 | 出剪影图 + 慢推；要跳舞就是 L3 |
| Y-D2 快推冲刺 | 效果 L1 | `punch` 做冲推；画面按来源另算 |
| Y-D4 滚转 | 效果 L1 | `spin`；画面按来源另算 |
| Y-D1 摄影机当舞者、跳舞、甩发、转身、走向镜头 | L3 | 必须 AI 视频（最好有参考视频驱动） |

## 四、分镜表里怎么写
- 每一刀加一列 **"制作"**，填 L1 / L2 / L3 / L4——**只填这一刀的画面从哪来**；冲推、白闪这类叠在上面的效果写在"动效"列，统一进代码与剪辑清单。
- L1 刀（AB 交替、甩镜、分屏、画中画）用到的画面如果要专门生成，那条 U 照样列进生成单元清单。**要生成的条数 = U 的总数**，包括只给 L1 刀当素材的那些。
- L3、L4 的刀写清楚"来自哪条生成单元（U）的第几秒"。
- L2 的刀写清楚"用哪张图（P 编号）+ 什么动法"，图片清单单独列。
- L1 的刀写清楚"用哪个 mvfx 命令 / 哪个剪辑效果"，做出来的小视频命名为 `L1_S几_说明.mp4`，镜头表直接填这个名字。
- 只给 L1 刀当素材的静图，也算进"要出几张图"，列进静图清单。
- 方案最后给一个**分级统计**：L1 几刀、L2 几刀（要出几张图）、L3 几刀（要生成几条）、L4 几刀。
