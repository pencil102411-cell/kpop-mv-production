# 视觉系统设计：世界、色彩、服装、母题、质感

> 女团 MV 好看的核心不是单个镜头，而是"系统"：观众一看颜色和服装就知道在哪个世界，一看到某个物件就想起这首歌。

---

## 一、世界（房间）系统

**一个世界 = 场景 + 服装 + 主色 + 光线方式**，四样一起换。

| 世界要素 | 写法 | 例子（LEMON） |
|---|---|---|
| 场景 | 空间形状 + 材质 + 标志物 | 弧形柠檬黄太空舱，圆形舷窗，黑色机械臂 |
| 服装 | 一句话造型锚点 | 黑色军装制服 + 银色徽章，部分成员军帽 |
| 主色 | 1 个主色 + 1 个辅色 | 柠檬黄 + 黑 |
| 光线 | 光源方向 + 硬/软 + 色温 | 舱壁整体发光的柔和顶光，舷窗白色逆光 |

**数量**：3 分钟的歌 3~5 个世界；预告片 1~2 个。
**分工**：每个世界负责一种情绪或一个段落类型。例：
- 白色无限空间 → 群舞锚点、点名人像（干净、看清楚）
- 复古酒吧 → 主歌叙事、母题物件（柠檬）
- 暗夜废墟 → 副歌大场面、高潮
- 黄色太空舱 → 预副歌、剪影、转场门户

**AI 制作要点**（按世界换装时）：每个世界先出 1~2 张空场景参考图 + 每个成员这一世界的定妆图，同一世界所有生成都挂这组图。

### 另一种写法：一套造型，换光不换衣（AI 制作的默认）
成员造型已经定稿、又要全 AI 制作时，**不按世界换衣服**：每人一套造型全片不换，换段落靠换**光**和换**场地的一角**。
- 例（《Red Line》）：同一个地下停车场，四个成员各守一个角落、各有一种光（荧光冷绿 / 手机闪光冷白 / 车尾灯红 / 昏黄旧灯）；副歌走到同一片红格子车位；主歌 2 全黑只剩绿色应急灯；爆点是满场手机光。
- 好处：设定图一人一张就够，不串人、不串衣服；用户换人物形象时也不用推翻世界系统。
- 世界表照样写四列，"服装"一列写"同一套"，把功夫花在"光"和"场景"上：相邻段落的光要拉开（冷绿 ↔ 红 ↔ 全黑）。

## 二、色彩系统

### 1. 强调色（串联色）
全片选 **1 个强调色**，在每个世界里都出现（服装细节、灯、道具、LOGO）。多人团可以"一人一样强调色细节"：同一种红，A 是脸上的小红心、B 是衣服上的红线、C 是红麦线、D 是红镜片墨镜——每人一样、不重复，群像里一眼分得清谁是谁。
- LEMON：柠檬黄绿　｜　UNA：克莱因蓝　｜　KV：大红　｜　HitEm：红色拳击鞋/粉色护腕（唯一暖色）

### 2. 世界主色对比
相邻出现的两个世界，主色要拉开：亮↔暗、暖↔冷、饱和↔低饱和。
- LEMON：白（亮）↔ 废墟（暗）↔ 黄（饱和）↔ 复古绿（暖）

### 3. 情绪与色彩（参考片里的实际用法）
| 色调 | 出现在 | 情绪 |
|---|---|---|
| 青灰低饱和 + 颗粒 | HitEm | 硬核、真实、汗水 |
| 冷蓝银灰 + CG 光洁 | UNA | 未来、空灵、非人 |
| 白色无限空间 | LEMON、KV、SHAKIN | 干净、时尚、聚焦人 |
| 暗夜 + 车灯/警灯 | XHS、LEMON | 叛逆、街头 |
| 黑白高反差 | KV、SHAKIN 漫画段 | 态度、杂志感、回忆 |
| 夜视绿 | SHAKIN 结尾 | 逃亡、失控 |
| 复古暖绿 | LEMON 酒吧 | 俏皮、复古 |

## 三、母题系统（让人记住这首歌）

**母题** = 反复出现的物件、符号、手势、画面。

| 类型 | 例子 | 出现方式 |
|---|---|---|
| 歌名物件 | LEMON 的柠檬 | 落水、飞过、在桌上滚、拿着杯子——每个世界都出现一次 |
| 符号 | UNA 的 ∞ | 玻璃罩里的 ∞、金属 ∞ 变形、星云 ∞、标题字 |
| 身体部位 | 眼睛（UNA、KV） | 眼睛睁开、瞳孔里有人、眼睛碎裂——当转场入口 |
| LOGO | XHS、KV | LOGO 环游世界、LOGO 材质轮换 |
| 手势 | 副歌记忆点动作 | 每遍副歌都给正面锚点镜头 |

**规则**：母题至少出现 4 次：开场埋一次、副歌强化、桥段变形、结尾回收。

## 四、质感层（全片滤镜）
**全片只选 1 套**，写成一句话，所有提示词都带：
- 胶片颗粒 + 圆形暗角 + 低饱和青灰（HitEm）
- CG 级光洁 + 冷蓝银灰 + 浅景深（UNA）
- 时尚棚拍高反差 + 冷灰蓝 + 大红色块（KV）
- 高饱和电影感 + 每世界单色（LEMON）

## 五、招牌构图（封面镜头）
每支 MV 需要 1~3 个"能截图当封面"的画面。参考片里的招牌：
- LEMON：白底上的椭圆门户里是另一个世界的群舞
- UNA：成员蜷坐在放射状黑色线缆中央（正俯拍）
- KV：暗仓库定机位里的燃烧王座 / 狼群
- SHAKIN：巨大白色光球前四人剪影
- HitEm：天窗体积光下的正面对称群舞
- XHS：车头灯逆光下马路正中的四人群舞

**写法**：用构图库的编号描述（见 `references/构图库.md`），并说明它出现在哪个段落。
