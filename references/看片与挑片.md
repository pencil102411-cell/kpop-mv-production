# 看片与挑片：生成结果怎么看、怎么挑、从第几秒用

> 流程 D 用。结论：**别在缩略图上下结论，别按整个画面的平均值下结论，别按提示词写的时间定入点。** 每批看完按 `templates/挑片结果模板.md` 记下来。

---

## 一、看什么、怎么看

| 要确认的 | 怎么看 | 实战里看错过的 |
|---|---|---|
| 动作做没做（抬眼、转头、甩发、推掌） | **把脸 / 手放大裁出来**，逐帧看（`mvfx sheet --every-frame`，或截出那一块） | 缩略图上把"抬眼""转头"看成没做，白白重跑了两条 |
| 灯光一盏盏亮、闪光灯此起彼伏 | **按画面里的灯的位置分区量亮度**，不要看整个画面的平均亮度 | 按平均亮度判成"只是整体变亮"，其实灯是从远到近一排排亮的 |
| 对口型的嘴有没有跟上原唱 | ① 量生成视频的音轨和原曲像不像（算两条音轨音量起伏曲线的相关度，1 = 一模一样；实战用上的在 0.83~0.99，越高越好；对不上的部分多在后半段，只用前半段也行）② 放大看嘴有没有在动、有没有被麦克风或头发挡住 | 用脸部关键点量嘴的开合和人声的相关，数很低但看片是对的——这个数不当结论，以看片为准 |
| 人是不是本人、衣服对不对 | 对照设定图看：脸、发型、专属细节（小红心、痣、墨镜、手表）、下装、帽子 | 首帧图里自带的眼镜去不掉；只给上半身参考时下装每个种子都不一样 |
| 有没有穿帮 | 走的方向、东西是不是自己动了、人是不是凭空出现、群众是不是在看镜头、画面里有没有长出字 | 四人倒着走；铜柱自己倒；门口的人隐身浮现；柱子上冒出 AI 写的字 |
| 景别对不对 | 第一秒是不是就是要的景别；有没有先给一段全身远景再推近 | 近景提示词写了地面 → 先出全身远景 |
| 画质 | 原尺寸看，别看放大或压缩过的版本；看脸上有没有鳞片纹、背景人脸有没有歪 | 二采精修让画面变脏，用户以为是模型本身的问题 |

- 每条都看完再挑，别看到第一条能用就停。
- 不确定的动作，把那几帧截给用户看，别凭印象说"做了"。

## 二、挑种子

- 对口型：两个种子先比音轨和原曲像不像，再比嘴露不露、动不动。像得多的那个通常嘴也对（实测同一批四人里某个种子四条全部更好，但不能指望每次都这样）。
- 动作镜头：比动作幅度、干不干净、落点在不在要的拍上；开头有没有多余的停顿。
- 两个都差不多时选**镜头更稳、景别更接近分镜**的那个。
- 两个都不行：先看是提示词的问题（对照 `AI生成逻辑.md` G15）还是首帧图的问题（G14），改了再跑，别只换种子硬跑。

---

## 三、找入点（这一刀从素材第几秒开始用）

1. **按动作实际发生的时间定**，不按提示词写的时间：实测动作常比写的晚 0.5~1.5 秒。先找到"这一刀要的那一下"（踩进水、手掌最近、剪影出现）在素材第几秒，再往前倒推这刀的长度。
2. **入点别从第 0 帧开始，也别定格第 0 帧**：生成视频第 0 帧到第 1 帧常常跳一下（画面差比后面大好几倍）。从 0.05 秒以后开始用；要定格就定格动作停稳的那一帧。实测：开头定格第 0 帧再接视频，看着像卡了一下。
3. **接了原曲的素材**：素材第几秒 = 歌里第几秒 − 原曲截取的起点。入点取一拍的整数倍，切点就卡在拍上。
4. **一条素材能给好几刀**：同一条的前段、后段分给相邻两刀，看着像同一镜头的延续（比切两条长得很像的素材顺）。
5. **模型自己切了一刀**：如果正好落在用得上的空拍上，可以留着；落在要用的段落里，就避开。
6. 动作不在拍上时，可以在剪辑里加速、倒放、定格一帧来凑拍（例：同一段往后 2 拍、两倍速倒放当下一刀）。
