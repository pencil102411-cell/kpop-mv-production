# MV 类型与概念套路

> 先选类型，再定概念。类型决定"镜头花在哪里"：舞蹈、世界观、人像、还是手法本身。
> 每种都标了 AI 友好度（★ 越多越适合 AI 生成）。

---

## 类型 1：舞蹈版 / Performance（参考 HitEm）
- **核心**：一个场景，镜头跟着编舞动；"看清动作"第一。
- **镜头分配**：群舞 50%、手持穿梭长镜 25%、局部碎片（鞋/手/甩发）15%、人像 10%。
- **剪辑**：中位 1.5 秒左右，长镜头多（5~9 秒）。
- **适合**：编舞是卖点的主打歌、舞蹈版 / 练习室版。
- **AI 友好度**：★★☆☆☆。需要编舞参考视频驱动；人数尽量 2~3（4~5 人必须有编舞参考视频，6 人以上必须降级）；碎片镜头多做。

## 类型 2：多世界概念 MV（参考 LEMON）
- **核心**：3~5 个平行"房间"，每个房间一套场景+服装+色板，歌曲段落在房间之间穿梭；1 个母题物件 + 1 个强调色串起来。
- **镜头分配**：每个世界都要有：群舞锚点、成员人像、母题物件、1 个招牌构图。
- **剪辑**：中位 1~1.5 秒，按 2 拍 / 4 拍规整剪。
- **适合**：大多数主打歌。最"标准"的女团 MV 结构。
- **AI 友好度**：★★★★☆。世界之间互不相连，每个世界单独锁参考图，一致性好管。

## 类型 3：数字偶像 / CG 科幻（参考 UNA）
- **核心**：人像 + 物件微距 + 穿越空镜，舞蹈很少；"美的定格"代替动作。节奏靠剪辑（AB 交替、频闪、闪切）制造。
- **镜头分配**：人像 40%、CG 物件/符号 25%、穿越/空间 20%、群像 15%。
- **剪辑**：中位 0.6 秒，大量 0.1 秒闪切。
- **适合**：虚拟偶像、电子/氛围感强的歌、预算有限但想要高级感。
- **AI 友好度**：★★★★★。**AI 做 MV 的首选路线。**

## 类型 4：杂志编辑 / 街头时尚（参考 KV）
- **核心**：摄影棚即舞台、排版即画面——定机位换景闪切、满屏字卡、动态歌词字、五官碎切、黑白高反差。
- **镜头分配**：群舞 25%、人像碎切 25%、定机位换景 15%、字卡 15%、生活段落 20%。
- **剪辑**：中位 0.3 秒，最激进；生活段落给 1~3 秒呼吸。
- **适合**：hip-hop、说唱多的歌、新团出道（要快速记住每张脸）。
- **AI 友好度**：★★★★☆。换景闪切、字卡、五官碎切都是"静帧+快剪"，成本低。

## 类型 5：叙事概念片 / 预告（参考 XHS）
- **核心**：两个对比世界（夜/日、街头/校园），用叙事小动作（喷漆、吃爆米花、自拍）讲人设；结尾一个 LOGO 蒙太奇。
- **镜头分配**：群舞 30%、叙事小动作 30%、人像 25%、蒙太奇 15%。
- **适合**：回归预告、概念片、出道预告。
- **AI 友好度**：★★★☆☆。叙事小动作涉及手和道具，要降级（虚化、远景）。

## 类型 6：元叙事 / 幕后即正片（参考 SHAKIN）
- **核心**：把"制作过程"做成内容——蓝幕、片场、监视器 UI、CG 线框、导演喊卡、画风切换。
- **AI 版改法**：把"AI 生成过程"做成概念——提示词文字滚动、草图、灰模、线框、失败的变形帧、多个生成版本交替闪切，和成片交替。
- **适合**：想制造话题、反差、"破第四面墙"的歌。
- **AI 友好度**：原版（需要真实片场）★☆☆☆☆；改成"AI 生成过程"版 ★★★★☆，失败帧本身就是素材。

## 概念的写法（一句话 + 三个支点）

**一句话概念**：`[谁] 在 [什么世界] 里 [做什么 / 经历什么]，用 [母题物件/符号] 串起来。`

例：
- LEMON：四个女孩在四个平行房间里，用一颗柠檬串起来。
- UNA：一个数字少女在太空站里醒来，∞ 符号是她的意识。
- KV：一群女孩把废弃仓库变成自己的杂志摄影棚。

**三个支点**（每个概念必须能回答）：
1. **世界**：有几个世界？每个世界一句话描述。
2. **母题**：哪个物件 / 符号 / 手势会反复出现？（歌名里的东西最好）
3. **招牌镜头**：哪 1~3 个画面是别的 MV 没有、可以当封面截图的？

## 从歌曲推导类型
| 歌曲特征 | 优先类型 |
|---|---|
| 编舞是最大卖点、节奏型强 | 舞蹈版（AI 制作时混入类型 3 的人像和物件降低难度） |
| 歌名是一个具体物件（柠檬、糖果、钥匙） | 多世界概念 + 物件母题 |
| 电子、氛围、太空感、旋律性强 | 数字偶像 / CG 科幻 |
| 说唱多、态度强、街头感 | 杂志编辑 / 街头 |
| 回归预告、出道预告 | 叙事概念片 |
| 歌词里有"假/真""镜头""表演"等元素 | 元叙事 |
